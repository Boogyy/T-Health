# Contributing

## Branches

- `main` — стабильная ветка.
- `feature/<task-name>` — новый функционал.
- `fix/<bug-name>` — исправления.
- `docs/<description>` — документация.

## Pull Requests

Перед merge в `main` нужно:

- создать Pull Request;
- получить минимум 1 approve;
- убедиться, что CI проходит (в будущем);
- решить все комментарии в PR;

## Commit style

Примеры:

```text
feat: add health endpoint
fix: configure postgres port
docs: add local setup guide
test: add context load test
```
